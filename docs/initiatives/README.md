# 추진안

이 파일은 현재 사람이 읽고 논의해야 하는 `initiative` 문서의 얇은 입구입니다. 사용자 화면과 대화에서는 `추진안`, 기술 surface에서는 `initiative`, stable ID에서는 `I####`를 사용합니다.

## Rules

- `Status: active`이고 `Approval Status: approved`인 문서만 적습니다.
- 각 항목은 링크, outcome 한 줄, owner, 연결 project, `Updated` 날짜를 보여줍니다.
- AI proposal, `draft`, `blocked`, stale approval은 active 목록에 올리지 않습니다.
- 문서를 닫으면 이 목록에서 제거하고 본문 `Status`와 `Outcome Review`에 근거를 남깁니다.
- 연결 프로젝트의 WBS와 task 상태를 복제하지 않고 stable ID와 관계만 표시합니다.

## Active

- 현재 active 추진안 문서가 없습니다.
