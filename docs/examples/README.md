# Examples

이 디렉터리는 placeholder를 실제 문서로 채우는 방식을 빠르게 보여주기 위한 완성형 샘플 모음입니다.

중요한 규칙:

- 예시 문서는 `docs/projects/`, `docs/tasks/`, `docs/design/` 밖에 둡니다.
- 따라서 이 저장소를 복사해도 실제 발급 번호는 `P0001`, `T0001`부터 시작합니다.
- 예시의 도메인은 설명용이며, 복사 후 그대로 재사용하지 않는 것을 권장합니다.
