# Projects

이 파일은 승인된 추진안 아래에서 현재 읽어야 하는 bounded `project` 문서의 얇은 입구입니다.

## Rules

- `Status: active` 인 문서만 적습니다.
- 각 project의 canonical `I####`를 함께 적습니다.
- 같은 initiative 안에서는 project 관계(`delivers`, `supports`, `explores`)와 delivery boundary가 드러나게 적습니다.
- legacy umbrella project는 migration 전까지 별도 compatibility 표기로 유지하며 승인된 추진안으로 자동 승격하지 않습니다.
- 각 항목은 링크, 한 줄 설명, `Updated` 날짜만 남깁니다.
- 문서를 닫으면 이 목록에서 제거하고 본문 `Status` 이력에 종료 근거를 남깁니다.

## Active

- 현재 active project 문서가 없습니다.
